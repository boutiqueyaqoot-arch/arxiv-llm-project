About arXivLLM Workspace

Welcome to **arXivLLM**, a high-fidelity workspace inspired by NotebookLM but customized specifically for handling multi-paper scientific research documents.

🛠 Key Features

  • Interactive Mindmaps: Map documents visually. Zoom/Pan and select any concept nodes for minimalist breakdowns.
  • Elegant Slide Decks: Effortlessly compile presentations directly inside the dashboard workspace.
  • Local PDF Extraction: No servers! We parse PDF text locally directly inside your browser.
  • Flexible API Connection: Powered natively using your own Gemini Key. Completely private.
Security Note: Your API Key is stored only in temporary memory inside your browser session and is never sent to any server except the Google Gemini official developer endpoint.
